# 智选 AI 商城 · 本地功能版

本版本在原有七款商品和视觉风格基础上，增加独立管理后台、账户认证、数据库、购物车、模拟订单、交付记录、模拟退款和客服留言。

## 打开网站

- 当前电脑：用户端 http://127.0.0.1:8766/ ，管理后台 http://127.0.0.1:8766/admin 。
- 以后使用：双击 `启动商城.cmd` 或 `打开管理后台.cmd`。启动窗口需要保持打开。
- 此版本需要 Python 3.10 或更新版本，全部使用 Python 自带模块，无需安装第三方依赖。
- 手动启动：在项目目录执行 `python server.py`，然后打开上面的地址。
- 服务器只监听本机。其他电脑或手机不能通过自己的 127.0.0.1 访问。
- 本版本不能双击 HTML 运行，必须先启动服务器。旧的单文件展示版仍保留在交付目录。

## 首次设置你的管理员

1. 双击 `打开管理后台.cmd`。
2. 启动窗口会显示本机初始化码，也可以查看项目中的 `data/setup-key.txt`。
3. 在后台页面输入初始化码，设置自己的管理员用户名、昵称和密码。
4. 用户名为 3–30 位字母、数字或下划线，密码至少 10 个字符。
5. 设置成功后，初始化接口立即失效，以后使用管理员用户名和密码登录。

没有预置管理员密码。初始化码只用于本机首次设置，不要转发给其他人。打包的项目不包含当前电脑的数据或初始化码；解压后首次启动会自行生成。

## 用户端

- 首页、商品列表、商品详情、关键词搜索、分类筛选、价格排序。
- 用户注册、登录、退出、修改昵称和密码。
- 登录后购物车自动保存，支持数量调整和移除。
- 创建订单时由服务器核实商品和价格，保存当时的名称、价格和数量。
- 创建订单 → 模拟支付 → 等待管理员记录演示交付 → 查看交付说明。
- 待支付订单可取消，模拟支付后可申请模拟退款。
- 客服包括本地规则问答，以及会保存的商家咨询留言。
- 用户只能读取和操作自己的订单、购物车与咨询记录。

## 管理后台

- 管理员独立入口；普通用户无法读取管理接口。
- 经营概览：上架商品、待交付订单、待回复咨询、模拟成交金额。
- 添加和编辑商品名称、价格、分类、设备类别、详情及上下架状态。
- 搜索订单，按状态筛选，填写演示交付说明，处理模拟退款。
- 查看必要的用户资料与订单数量；不显示密码。
- 回复用户留言。
- 修改商城名称、首页公告与客服说明。
- 修改管理员密码。

同一浏览器的用户端和后台共用登录会话。若需同时以店主和顾客身份体验，请使用两个浏览器或一个无痕窗口。

## 数据与备份

数据保存在 `data/shop.sqlite3` 中，刷新页面或重启服务不会清空。密码采用带随机盐的 PBKDF2 哈希，不保存明文密码；会话使用 HttpOnly Cookie。

运行 `python backup.py` 可将一致性数据库备份保存到 `backups/`。恢复时先关闭服务，保留原数据备份后，再以备份文件替换 `data/shop.sqlite3`；不要混用运行中数据库的 WAL 文件。数据和备份包含账户及订单信息，请妥善保管。

## 演示边界

- 真实微信支付、支付宝、订阅充值和自动发货均未接入。
- “模拟支付”“模拟退款”只更新数据库状态，不涉及真实资金。
- 后台“交付”仅记录演示说明，不会开通第三方订阅。
- 商品与报价沿用原稿，仅供体验；已将“官网最新”表述改为“原稿标注”，未核验其现实有效性。
- 客服是本地规则回复，没有连接外部 AI 接口。
- 尚未部署到公网。对外营业前需另行配置域名、HTTPS、线上数据库与备份、账户找回、邮件或短信验证、正式支付及业务资料。

## 验证

运行 `python tests/test_api.py` 可测试独立临时数据库，不影响你的商城数据。浏览器验收结果见同目录的《验收结果.md》。
